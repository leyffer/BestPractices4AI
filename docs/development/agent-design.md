# Agent Design

Patterns and best practices for designing reliable AI agents and tool-using workflows.

- **[AGENTS.md](https://agents.md/)** open format for guiding coding agents (example: [JuMP's AGENTS.md](https://github.com/jump-dev/JuMP.jl/blob/master/AGENTS.md))
- **[AI Agents for Scientific Discovery](https://agents4science.github.io/)** combines reasoning-capable AI with scientific and engineering resources
