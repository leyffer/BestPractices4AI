# Resources

A curated list of tools, papers, and links for working with AI.

- **[Claude Code 101 Hackathon](https://github.com/wilke/claude-code-101)** — Claude Code as a co-scientist: workshop

## Argonne-Specific Resources 

These Argonne-specific resources *require Argonne login*.

- **[Argo API Documentation](https://anl.app.box.com/notes/1444961193376?s=ubtrsefonqeo9xppdzcurezy8rzsbs96)** — connecting to argo/API
- **[Claude code + argo outside of CELS with argo-shim](https://github.com/n-getty/argo-shim)** — A lightweight HTTP proxy that lets Claude Code talk to the Argo API through an SSH tunnel 
- **[Using AI development tools outside the Argonne trusted network](https://web.cels.anl.gov/~jacob/ai4dev.html)** — Rob Jacob's guide on how to use argo outside Argonne
- **[Vibe Coding with Argo](https://anl.app.box.com/notes/1871610644419?s=hxc72dkm0a8mlmo7ownfl4ixwx6iu3ko)** — using argo with claude, opencode, VSCode, aider, ...
- **[Vibe Coding Hackathon](https://anl.app.box.com/s/iva9qhm478a29pt3lt4yy53ubhdrs239)** — 2025 Vibe Coding Workshop at Argonne
